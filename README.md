# `fabrishot`
A minimal Fabric port of [mineshot](https://github.com/ata4/mineshot) which supports high resolution screenshots, Supports saving as PNG, JPG, WebP, AVIF, and TIFF.  
Install the Flashback mod to enable full functionality.

[CurseForge page](https://www.curseforge.com/minecraft/mc-mods/fabrishot)
